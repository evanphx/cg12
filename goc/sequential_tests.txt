# Tests in the goc suite that must NOT run concurrently with other tests.
#
# Every other top-level test in this package calls t.Parallel as its first
# statement; goc/parallelpolicy_test.go enforces both directions against this
# file, and scripts/verify.sh reads it to shard the suite. It is the single
# source of truth, so a name added here needs no other edit.
#
# Go runs every sequential top-level test to completion BEFORE it resumes any
# parallel one, so a test listed here is guaranteed a quiet process: no other
# test in this package is compiling while it runs. That guarantee is the whole
# point of the list.
#
# Format: <test name> <tab> <reason tag>
#
# placement  Asserts WHERE the compiler put an allocation -- a frame or the
#            heap -- directly, or through a helper, or through the corpus-wide
#            audit baselines. Measured on this box: running the suite at
#            -parallel 32 with these tests parallel makes TestAllocationCensus,
#            TestFrameEscapeAudit and TestInterfaceConversionsCallTheRuntimeHelpers
#            fail, every difference in the conservative direction (an allocation
#            the serial run keeps in a frame is on the heap). The same tests pass
#            at -parallel 32 when nothing else in the process is compiling, and
#            they still fail with CG12_NOCACHE=1, so the shared source world is
#            not the mechanism. Concurrent compiles inside ONE process perturb
#            escape placement; nothing in production does that (goc compiles one
#            program per process, and `goc compile-batch` compiles its stream
#            strictly in sequence within each worker), so this is a constraint on
#            how the suite may be parallelised rather than a shipped defect.
#            The set is deliberately over-broad: it is every test that reaches a
#            placement assertion by any call path, not only the three that were
#            observed to fail.
#
#            THE ROOT CAUSE IS NOW ISOLATED, and it is one line of test code, not
#            the compiler. TestEscapeSummaryCost sets the package-global
#            opt.EscapeSummaries to false across three whole-program compiles of
#            stdlib_crypto_ecdsa.go to price the fact table; every compile in the
#            process reads that variable at opt/escape.go, so anything compiling
#            inside that window gets the analysis with no callee summaries -- the
#            assume-every-call-escapes arm. `analysis/escapedrift` reduces it to
#            two goroutines and a handshake and flips three placements every run.
#            The drift is not intrinsically conservative: its direction follows
#            GOC_ESCAPE_SUMMARIES, and under that variable's documented bisection
#            setting the same reduction moves allocations INTO frames. Both knob
#            settings are placements the compiler ships, so nothing unsound is
#            reachable. See CCWORK_REPORT.md.
#
#            What that licenses, and what it does not: only the two tests that
#            write the knob (TestEscapeSummaryCost, TestEscapeSummaryPromotionRate)
#            need this tag for that reason, so most of the placement entries below
#            could go back to parallel. That was NOT done here, because showing it
#            means running the census, the audits and the corpus suite, which this
#            job was scoped out of. Whoever narrows the list should run those three
#            named tests at -parallel 32 first. The Test*Diagnostic* and
#            TestEscapeReason*/TestGocFlagM* entries move opt's diagnostic level
#            and writer instead; that is measurably placement-neutral, but they
#            race each other, so they need a tag of their own rather than removal.
# census     Installs the package-global generic-instantiation sink that
#            goc/genericshape.go's compile() hook writes into, so a compile
#            started by any other test in the process would be recorded in this
#            one's census. TestGenericShapeCensus is flag-gated
#            (-generic-shape-census) and skips in a normal run;
#            TestGenericInstanceSymbolMatchesTheCompilersOwnAnswer is not -- it
#            costs one small compile of serial time and it is what holds
#            goc/functioncache.go's name-based instantiation predicate to the
#            type arguments the compiler actually recorded.
# setenv     Calls t.Setenv, which mutates process-global state and panics if the
#            test is parallel.
# timing     Measures elapsed time on a pinned core and has a pre-flight that
#            refuses a busy box. Flag-gated, so it skips in a normal run.
# inlinedeps Installs opt's process-global inline-dependency recorder, which
#            panics rather than nest and would otherwise record whatever else in
#            the process happened to be optimising.
